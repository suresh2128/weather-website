![image](https://github.com/user-attachments/assets/88dbbf98-6d27-4878-ad56-a6ccfe35c209)# Weather App

  A simple and elegant weather application that allows users to check the current weather conditions of any city worldwide. Built with modern web technologies and a focus on clean UI/UX.

##🚀 Features

🌍 Search weather by city name

📍 Get real-time weather updates based on your location

🌤️ Display temperature, humidity, wind speed, weather condition, etc.

📅 5-day weather forecast (optional if implemented)

🌗 Responsive design for all screen sizes


## 🛠️ Tech Stack

HTML5

CSS3 / TailwindCSS / Bootstrap (choose one)

JavaScript / React.js (if used)

OpenWeatherMap API (or any other weather API used)


# 📦 Installation

  ---> downlaod the project zip file extract the file
  ---> then open the file in the vscode
  ---> open the terminal type "npm install"   these command install the requried packages for the code
  --->  then run the file using these command "npm run dev"
